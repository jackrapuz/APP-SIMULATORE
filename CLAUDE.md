# Sim Racing Learning App — Project Context

## Utente
- Nome: Giacomo, principiante assoluto sim racing
- Obiettivo: arrivare a livello racing competitivo partendo da zero
- Lingua app: italiano
- Sistema: PC Windows, monitor singolo, stand monitor

## Hardware acquistato
- Base: Fanatec CSL DD QR2 (8 Nm con Boost Kit 180)
- Volante: ClubSport Steering Wheel RS
- Pedali: ClubSport Pedals V3 (con load cell)
- Shifter: ClubSport Shifter SQ V1.5 (H-pattern + sequenziale)
- Cockpit: CSL Cockpit V1.5 + Seat Bundle
- Accessori: Shifter Holder, Seat Sliders

## Software target
- Assetto Corsa (primario)
- ACC (medio termine)
- iRacing (lungo termine)

## Interessi personali rilevanti
- Cultura JDM, Mazda RX-7 FD (target auto a lungo termine)
- Initial D, touge driving
- Italiano, lavora in ingegneria meccanica

## Vincoli tecnici dell'app
- Deve essere HTML standalone (no build step, no npm install per usarla)
- Funziona offline una volta caricata
- localStorage per persistenza
- Responsive ma ottimizzata per desktop
- Italiano in tutta l'app
